# 의류 벤더 샘플 업무 검색 도우미

여러 엑셀 파일, 메신저 대화, 샘플실 메모에 흩어진 정보를 한 화면에서 찾는다는 상황을 구현한 포트폴리오 프로젝트입니다. 합성 샘플 120건을 사용하므로 실제 회사 정보는 포함하지 않습니다.

## 그래서 무엇이 편해지나요?

예를 들어 바이어가 “NOVA 네이비 재킷 샘플 지금 어디 있나요?”라고 물었다고 가정합니다.

기존에는 담당자가 엑셀 행을 찾고, 메신저에서 진행 상황을 확인하고, 샘플실에 위치를 다시 물어볼 수 있습니다. 이 도구에서는 **`NOVA 네이비 재킷`**이라고 입력하면 다음 정보를 한 번에 봅니다.

- 어떤 브랜드·시즌·품목인지
- 무슨 색상과 소재인지
- 요청 접수, 준비, 검수, 발송 중 어느 단계인지
- 샘플이 어느 선반에 보관되어 있는지
- 언제까지 처리해야 하는지

즉, 샘플을 직접 생산하거나 검수하는 프로그램이 아니라 **샘플 관련 문의에 답하고, 위치를 찾고, 진행 상황과 납기를 확인하는 시간을 줄이는 검색·조회 도구**입니다.

## 바로 사용해 보기

서버를 실행한 뒤 아래 주소를 여세요.

- **현업용 한국어 화면:** http://127.0.0.1:8000/
- 개발자용 API 시험 화면: http://127.0.0.1:8000/docs

첫 화면에서 다음과 같이 시험해 볼 수 있습니다.

1. `네이비 재킷 검수`를 검색해 관련 샘플을 찾습니다.
2. 브랜드 또는 진행 상태를 선택해 담당 업무만 좁혀 봅니다.
3. 검색 결과에서 보관 위치와 납기일을 바로 확인합니다.

## 구현 기능

- 합성 의류 샘플 데이터 120건 자동 생성
- SQLite 저장 및 브랜드·상태 필터 조회
- Pydantic 기반 입력 검증과 중복 데이터 409 응답
- TF-IDF 기반 한글 유사 검색과 일치 필드 표시
- 검색 처리시간 측정
- 비개발자도 사용할 수 있는 한국어 샘플 검색 화면 (`/`)
- 업무 표현으로 정리한 Swagger API 문서 (`/docs`)
- pytest API·검색 테스트
- Docker 및 docker-compose 실행 환경

## 기술 스택

`Python 3.12` `FastAPI` `Pydantic` `SQLite` `pandas` `scikit-learn` `pytest` `Docker`

## 실행

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m app.seed
uvicorn app.main:app --reload
```

- 업무 화면: http://127.0.0.1:8000/
- API 문서: http://127.0.0.1:8000/docs
- 상태 확인: http://127.0.0.1:8000/health

## API 예시

```bash
curl -X POST http://127.0.0.1:8000/api/v1/search \
  -H "Content-Type: application/json" \
  -d '{"query":"네이비 재킷 검수","limit":3}'
```

## 테스트와 벤치마크

```bash
pytest -q
python scripts/benchmark.py
```

로컬 Windows/Python 3.12 환경 실측 결과:

- 자동화 테스트: **6개 전체 통과**
- 검색 대상: **합성 데이터 120건**
- 검색 실행: **100회**
- 평균 검색시간: **7.22ms**
- P95 검색시간: **7.70ms**
- 최대 검색시간: **9.62ms**

환경에 따라 결과는 달라질 수 있으며 `python scripts/benchmark.py`로 재측정할 수 있습니다.

## 데이터 및 보안

프로젝트의 데이터는 실제 회사·바이어 자료가 아닌 규칙 기반 합성 데이터입니다. 회사 정보, 고객정보, 실제 샘플 번호는 포함하지 않습니다.

## 구조

```text
app/
  main.py          # FastAPI 엔드포인트
  database.py      # SQLite 연결·스키마
  repository.py    # 데이터 접근 계층
  search.py        # TF-IDF 검색
  schemas.py       # Pydantic 모델
  seed.py          # 합성 데이터 생성
tests/             # API·검색 테스트
scripts/benchmark.py
```
